# 딴 짓 리더보드

팀장님이 보면 한숨이 나올 만한, 그러나 사용자 입장에서는 매우 직관적인 **딴 짓 시간 리더보드**입니다. 이름, 딴 짓 종류, 시간을 입력하면 누적 기록을 바탕으로 순위를 자동 계산합니다.

## 주요 기능

### 1. 딴 짓 기록 등록

- 이름, 딴 짓 종류, 시간을 입력해 새 기록을 등록합니다.
- 같은 이름으로 다시 등록하면 기존 사람의 딴 짓 목록에 기록이 합쳐집니다.
- 이미 같은 딴 짓을 한 적이 있으면 기존 항목의 시간이 증가합니다.
- 같은 사람에게 처음 등록되는 딴 짓이면 새 딴 짓 항목이 추가됩니다.
- 시간은 분 단위로 입력합니다.
- 이름이 비어 있거나 시간이 0 이하이면 등록 버튼이 비활성화됩니다.
- 등록 후 폼은 자동으로 초기화됩니다.

### 2. 새로운 딴 짓 종류 등록

- 기본 딴 짓 종류 외에 원하는 딴 짓을 직접 등록할 수 있습니다.
- 등록된 종류는 입력 폼의 선택 목록에 즉시 반영됩니다.
- 기록 입력 중 `직접 입력`을 선택해 바로 새 딴 짓 이름으로 기록할 수도 있습니다.
- 중복된 딴 짓 종류는 다시 등록되지 않습니다.

### 3. Redux Toolkit 기반 상태 관리

- `configureStore`로 전역 스토어를 구성했습니다.
- `createSlice`로 딴 짓 기록 추가, 딴 짓 종류 등록, 사람 삭제, 특정 딴 짓 삭제, 전체 초기화 액션을 관리합니다.
- 같은 이름은 같은 사람으로 합산하고, 같은 딴 짓 종류는 시간을 누적합니다.
- `prepare` 콜백에서 입력값을 정리하고 등록 시각을 자동 생성합니다.
- selector를 통해 사람별 총시간, 대표 딴 짓, 정렬된 리더보드, 요약 통계를 계산합니다.

### 4. 실시간 리더보드

- 사람별 총 딴 짓 시간이 긴 순서대로 자동 정렬됩니다.
- 시간이 같으면 먼저 등록된 사람이 더 높은 순위를 얻습니다.
- 순위, 이름, 딴 짓별 누적 시간, 총 시간, 삭제 버튼을 표로 제공합니다.
- 딴 짓 칩의 삭제 버튼으로 특정 사람의 특정 딴 짓만 제거할 수 있습니다.

### 5. 상위 3명 포디움

- 상위 3명의 기록을 카드 형태로 강조합니다.
- 1위 카드는 더 눈에 띄는 하늘색 그라데이션으로 표현했습니다.

### 6. 요약 통계

- 총 딴 짓 시간
- 평균 딴 짓 시간
- 가장 많이 등록된 딴 짓 종류
- 현재 딴짓왕 정보

### 7. 세련된 화이트 & 연한 하늘색 디자인

- 전체 톤은 화이트와 연한 하늘색을 중심으로 구성했습니다.
- 카드형 레이아웃, 부드러운 그림자, 반투명 배경, 라운드 UI를 사용했습니다.
- 모바일 화면에서도 자연스럽게 보이도록 반응형 레이아웃을 적용했습니다.

## 상태 관리 흐름

1. 사용자가 폼에 이름, 딴 짓 종류, 시간을 입력합니다.
2. 폼 제출 시 `addDistraction` 액션을 dispatch합니다.
3. slice가 같은 이름의 사람이 있는지 확인합니다.
4. 같은 사람이 없으면 새 사람과 첫 딴 짓을 생성합니다.
5. 같은 사람이 있고 같은 딴 짓이 있으면 기존 딴 짓 시간에 입력 시간이 더해집니다.
6. 같은 사람이지만 처음 하는 딴 짓이면 해당 사람의 딴 짓 목록에 새 항목을 추가합니다.
7. selector가 사람별 총 딴 짓 시간을 계산하고 순위를 정렬합니다.
8. 화면의 포디움, 통계 카드, 테이블이 자동 갱신됩니다.
