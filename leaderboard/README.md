# 딴 짓 리더보드

팀장님이 보면 한숨이 나올 만한, 그러나 사용자 입장에서는 매우 직관적인 **딴 짓 시간 리더보드**입니다. 이름, 딴 짓 종류, 시간을 입력하면 누적 기록을 바탕으로 순위를 자동 계산합니다.

## 주요 기능

### 1. 딴 짓 기록 등록

- 이름, 딴 짓 종류, 시간을 입력해 새 기록을 등록합니다.
- 시간은 분 단위로 입력합니다.
- 이름이 비어 있거나 시간이 0 이하이면 등록 버튼이 비활성화됩니다.
- 등록 후 폼은 자동으로 초기화됩니다.

### 2. Redux Toolkit 기반 상태 관리

- `configureStore`로 전역 스토어를 구성했습니다.
- `createSlice`로 딴 짓 기록 추가, 삭제, 전체 초기화 액션을 관리합니다.
- `prepare` 콜백에서 `nanoid`와 등록 시각을 자동 생성합니다.
- selector를 통해 정렬된 리더보드와 요약 통계를 계산합니다.

### 3. 실시간 리더보드

- 딴 짓 시간이 긴 사람부터 자동 정렬됩니다.
- 시간이 같으면 먼저 등록된 기록이 더 높은 순위를 얻습니다.
- 순위, 이름, 딴 짓 종류, 시간, 등록 시각, 삭제 버튼을 표로 제공합니다.

### 4. 상위 3명 포디움

- 상위 3명의 기록을 카드 형태로 강조합니다.
- 1위 카드는 더 눈에 띄는 하늘색 그라데이션으로 표현했습니다.

### 5. 요약 통계

- 총 딴 짓 시간
- 평균 딴 짓 시간
- 가장 많이 등록된 딴 짓 종류
- 현재 딴짓왕 정보

### 6. 세련된 화이트 & 연한 하늘색 디자인

- 전체 톤은 화이트와 연한 하늘색을 중심으로 구성했습니다.
- 카드형 레이아웃, 부드러운 그림자, 반투명 배경, 라운드 UI를 사용했습니다.
- 모바일 화면에서도 자연스럽게 보이도록 반응형 레이아웃을 적용했습니다.

## 상태 관리 흐름

1. 사용자가 폼에 이름, 딴 짓 종류, 시간을 입력합니다.
2. 폼 제출 시 `addDistraction` 액션을 dispatch합니다.
3. slice의 `prepare`에서 고유 ID와 등록 시각을 추가합니다.
4. Redux store에 기록이 저장됩니다.
5. selector가 전체 기록을 시간 기준으로 정렬합니다.
6. 화면의 포디움, 통계 카드, 테이블이 자동 갱신됩니다.
