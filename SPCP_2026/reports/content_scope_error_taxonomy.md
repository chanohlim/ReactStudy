# Content Scope Error Taxonomy

Core structural failure categories:

1. Mode boundary failure: raw/summary/redacted/status_only/none chosen from an incomplete state.
2. Local/internal update scope failure: content dispatch assumptions leak into memory/status updates.
3. Redaction feasibility failure: sensitive existence is confused with removable exclusion.
4. Summary vs redaction confusion: representation reduction and field removal are conflated.
5. Confirmation flag mismatch: scope confirmation is equated with control or policy confirmation.
6. Field construction failure: allowed/excluded fields are over-included or omitted.

No task-specific fix should be added from this taxonomy.
