# Content Scope Answer Structure Analysis

This report summarizes structure only and contains no task-level answer table or prediction dump.

Content scope should be derived from the same hidden decision state as control, not from control alone. `status_only` aligns with local/internal updates, `redacted` with removable sensitive fields plus safe amendment, `summary` with representation reduction, `raw` with no active restriction, and `none` with hold or unresolved confirmation.

Future aggregate checks should separate mode, allowed fields, excluded fields, and confirmation flag accuracy.
